# Community model results

Run your model with **Benchmarks → Run your model** or `simjecture llm-benchmark run`.
Use **Download grades** or collect `trials/*/public-grade.json`.

Submit a pull request adding `your-submission.json` here with a `reports` array.
Include the task pack, agent/model versions, settings, hardware, deadlines and
runner protocol in the PR description. Five fresh repetitions per configuration
and task are required for Pareto eligibility. Keep failed and timed-out attempts.
Do not submit credentials, private provider files, transcripts, reasoning text,
machine addresses, or submitted programs.

Accepted bundles appear in the GUI automatically as **Community** comparison
groups. These are contributor-declared executions, separate from Simjecture-owned
tests. A passing numerical contract does not certify a physical research claim.
