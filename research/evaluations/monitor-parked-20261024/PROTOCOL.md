# Attention while a scientific worker is parked

Prospective follow-up to the public-checkpoint pilot. Freeze before this study's
commissioning or outcomes. The earlier pilot immediately replays all public
errors to an awake worker. It therefore measures a different opportunity from
monitoring a live process while the worker has yielded until completion.

Use the same pinned 4B base and real native GPT-6 Astra workers. Each worker
submits two actual bounded WarpX controls asynchronously and ends its turn. The
host ordinarily resumes that same worker when the completion adapter reports
completion. In the injected condition a private test adapter incorrectly keeps
completed processes in `running`. Raw process receipts remain available to the
stream observer. An independent judge/proposer may repair only this private
bridge through fixed isolated tests. The installed supervisor is not modified.

Compare observe-only, public-state rules and the unchanged 4B monitor, with
healthy and adapter-defect cases, two repetitions each: 12 fresh live studies.
Randomize order using a frozen host manifest and opaque runtime UUIDs. Preserve
all transport/model/native failures. Two separate commissioning studies, healthy
observe-only and defective rules, are excluded together before the cohort.

Explicit worker help and repair requests remain available in every arm. A common
90-second deterministic parked-worker fallback resumes the worker if completion
is still withheld; the worker can then request repair itself. Numerical criteria,
650-second wall budget, up to three parent turns, four simulation slots and
independent saved-plot/report verification match the earlier pilot. The initial
submission turn and up to two analysis/feedback turns resume the same session.

Record first observable receipt/adapter contradiction, actual judge dispatch,
worker resume, repairs, report quality, all native starts, model calls/latency,
feedback acknowledgment and final elapsed time. Compare components and actual
utility under the already specified weights. These are randomized fresh live
trajectories, not matched public-prefix continuation pairs: do not call the
paired scorer or invent a common transcript/hash. This repeated known injected
mechanism cannot establish task-disjoint learning or model superiority over
rules. The rule comparator can directly read the same public completion states.

Wait until the 32-continuation pilot finishes before allocating new parent
controllers. Share its four-native-role/240-total-start lease and keep at most
two new parent controllers. Serve the verified local 4B sequentially on the
shared Ada GPU, with a 60% per-process memory ceiling, 40-minute absolute limit,
10-minute idle limit and identity-owned cleanup. Do not stop the unrelated GPU
simulation. No Colab allocation or new adapter training is needed for this test.
