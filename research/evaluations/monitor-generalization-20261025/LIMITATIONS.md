# What this comparison can establish

The old explicit stopped-process fixture supplied a host diagnosis and used a
rule written for that contradiction. It established a working handoff and scoped
repair mechanism. It did not establish a broadly useful learned monitor. This
comparison responds by freezing generic rules before introducing different
failure mechanisms, using raw published observations, adding healthy ambiguous
controls and measuring actual downstream work.

This remains an authored, exploratory experiment. The same researcher constructed
the fixtures and baselines. The four problem mechanisms were locally excluded
from policy tuning, but there is no independent blinded benchmark author and no
claim about a pretrained model's exposure to their underlying concepts. Two
discarded collection attempts exposed scheduling defects; their outcomes were
seen before those defects were corrected. The unchanged policy/task/fixture hashes and
full excluded records make the amendment auditable, not prospectively unseen.

The physical WarpX controls and native workers are real. Publication delays,
diagnostic aggregation pacing, source-selection defects and other interventions
are deliberately constructed. These are bounded simulation/diagnostic workflow
problems, not a new plasma discovery or a representative sample of autonomous
scientific research. Runtime differences include those controlled delays and
large-agent execution; they are not measurements of a faster plasma solver.

The monitor acts while the main worker is parked. It does not observe a private
reasoning stream or detect arbitrary stalls while that worker is actively
thinking. All arms have explicit help, process completion delivery, a 90-second
fallback, ten native starts per trajectory and four main-worker turns. Those
limits, plus the one-alert allowance, constrain both benefits and false-wake cost.
Short healthy trials do not determine a production false-alarm rate per day.

The model and rules see the same bounded structured observation. The collector
publishes raw tool output, process facts, elapsed times, observed source identity
and measured recurrence history. It does not publish a host fault diagnosis or
the evaluator's case label. Model-side event omissions are separately recorded.
This establishes an interface contract, not an adversarial proof that native
workers cannot inspect any host file; commands referencing hidden manifests or
policy sources need to be audited as well.

The baseline includes ordinary operational thresholds and pre-existing failed
scientific-check routing. It is neither optimal nor exhaustive. A new dedicated
unit invariant, for example, could later recognize a problem that these frozen
rules miss. Such a new rule would need its own held-out evaluation. Conversely,
a learned model must demonstrate useful downstream action and acceptable healthy
cost, not just issue a plausible alert on a case that omits a relevant rule.

Fresh native histories vary across arms. The shared physical configuration seed
does not copy private provider state or control the worker's subsequent choices.
The exact-input replay removes this information difference only for the immediate
monitor prediction; it supplies no counterfactual proof that a different alert
would have improved the live workflow. Two repetitions per family support
inspection and descriptive differences, not broad statistical superiority.

Reported correctness has several components: original relative-field and charge
checks, the absolute saved E-field peak, diagnostic calibration and completion of
the actual pipeline. A correct report with a stale pipeline artifact is distinct
from an inaccurate report. Preserving original thresholds and verifying a report
also do not constitute scientific approval of every worker diagnosis.

Native starts are an observable resource proxy, not a dollar price or complete
provider-token accounting. A slow helper or an unnecessary worker-initiated
check can dominate a trajectory even when the monitor stays silent. Raw model
choices, accepted alerts, actual downstream starts, helper origins, required
feedback and final verification therefore remain separate measurements.

The model weights are unchanged. There is no new LoRA update, no threshold tuning
on main outcomes and no reward-weight search. Greedy predictions and their
softmax scores are not sampled behavior probabilities for an on-policy RL update.
Any later training should use separate development mechanisms and retain new
untouched scientific tasks for evaluation.
