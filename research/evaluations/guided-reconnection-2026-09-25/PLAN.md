# Guided reconnection regression

The prior island-coalescence campaign supplied a validated application AND an
HDF5/flux-analysis pipeline. The September 24 open-end study did not have an
analogous production anchor. Comparing their outcomes does not isolate workflow.

## Readiness prerequisite

Reproduce `demos/resistive_mhd_island_coalescence/guided_commission.json` unchanged,
using the installed island-coalescence executable. Preserve its package and

not scientific support. Do not consume a research-agent budget until this works.

## Paired regression pilot

One 600-second trial each of minimal and structured, requesting GLM 5.3 through
codex-glm. Both receive the same root hypothesis, guided package, capability,
operator instructions, 300-second worker interval, Bubblewrap execution and
four-MPI-rank concurrency allowance per study. Same shared local host; launches
are staggered by approximately one second, so timing is descriptive rather than
a controlled speed ranking. No mid-run operator steering or implementation fixes.
The source-hash manifest and exact launch records remain in the private trial
folder. The initial structured launch failed before any model call on a trailing
newline comparison. A subsequent pair was stopped and excluded when the private
runtime lacked classic mode's preflight parameter file. Both the explicit anchor
and classic automatic preflight passed before the corrected pair was launched.

Measure separately:

- reproduced anchor and time to first fresh solver output;
- executed parameter cases, reached flux windows and refined cases;
- usable scientific measurements and correct uncertainty interpretation;
- accepted claims versus adequate partial scientific output;
- source/reader failures, contract failures, and reviewer overhead;
- worker plus reviewer input, cached-input and output tokens when reported.

An overlapping confidence interval does not reject an entire exponent interval
merely because one endpoint lies outside it. Test the actual bounded claim and
its spatial/regime qualifications. Supplied anchor values and the old audit fit
are not new evidence. A single pilot cannot select a default mode or establish
a completion-rate difference. The full six-hour original is a later replication,
not what this short pilot measures.
