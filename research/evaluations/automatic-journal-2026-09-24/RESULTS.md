# Automatic experiment journal — 2026-09-24

Minimal mode now maintains and supplies its research journal automatically. This
finishes the controller integration suggested by the inspected AIDE implementation;
researchers no longer have to elect to write notes, link attempts, or open a brief to
receive experiment history.

## Reference and implementation

AIDE's [agent loop](https://github.com/WecoAI/aideml/blob/60b3978ddf65b71f86eb7c64506965048a1398cf/aide/agent.py)
automatically appends result nodes and supplies its journal summary in generation prompts.
Its [journal](https://github.com/WecoAI/aideml/blob/60b3978ddf65b71f86eb7c64506965048a1398cf/aide/journal.py)
retains plans, code, execution information and relationships. We adopt that controller-owned
pattern using Simjecture's existing experiment receipts and native-agent transport. No
AIDE code is copied and no new framework dependency is added.

Automatic behavior:

- Record every service-recorded attempt, including failures and cancellation, with
  source/input/runtime identities, command arguments, execution timing, bounded error
  details, and hash-checked scalar result excerpts.
- Link preceding attempts sharing an entrypoint and detect implementation changes.
  These are explicitly chronological/source relationships, not inferred causal or
  hypothesis relationships. Explicit researcher parent links remain distinct.
- Supply a bounded current journal view **directly in every worker prompt**, including
  fresh sessions and recovery. The worker need not call a memory API or open a file.
- Preserve full receipts, generated ledger and an extended brief for deeper inspection;
  count entries omitted from the bounded context rather than silently dropping history.
- At meaningful checkpoints, perform a bounded tool-free synthesis using the configured
  reviewer model. Summaries distinguish observations, interpretations, questions and
  proposed tests, and may cite only experiments actually supplied to that call.

Factual bookkeeping is automatic. Synthesis is rate- and budget-limited: 45 seconds per
call, at least five minutes between attempts, and cumulative runtime allowance of the
lesser of 300 seconds or 3% of the study budget. The call needs at least 15 seconds of
allowance and 90 seconds of remaining study time. Small tasks use factual entries alone.
Claim/method review takes priority. Standard process-shutdown grace applies. Provider,
format or citation errors defer synthesis without stopping the researcher.

Summary authority is `controller_summary_unreviewed`. Summaries cannot approve, falsify,
repair or rewrite scientific claims. Reported metrics and passed flags are not validated
physics. Notes remain available for researcher enrichment, but are no longer the only
source of meaningful recovery context. Native scratch work outside the evidence service
is not automatically classified as a scientific experiment.

## Validation without voluntary recorder calls

The live MiMo v2.6 Pro check executed three real small arithmetic programs: an off-by-one
baseline, an intentional runtime failure, and a corrected calculation. No `lab.note`,
`parent_experiment`, `purpose` or test-plan metadata was supplied.

The controller produced **three journal entries and one checkpoint summary**, preserving
all attempts and source transitions. Synthesis took **31.0 seconds** and reported
**8,748 input + 736 output = 9,484 tokens**, with no cached input. The original claim
remained unaccepted: memory synthesis did not acquire adjudication authority.

The summary and recovery comparison use the core implementation before the final minor
addition of an error-message tail and a clearer status label. Those additions were tested
separately; they do not change summary scheduling, prompt injection, or acceptance rules.

## Controlled recovery comparison

`recovery_ablation.py` gives the same model the same byte-identical raw records and the
same seven factual recovery questions. It changes only delivery:

1. Plain agent: raw files and the recovery task.
2. Previous minimal-style delivery: an optional brief generated by the previous notebook
   implementation and a read-only status helper backed by the frozen snapshot.
3. Automatic journal: the host supplies the new bounded journal in the prompt.

Each condition gets 120 seconds and the same native CLI model/tools. This is a small
**context-delivery ablation**, not a full comparison of research systems or their scientific
completion rates. One trial per condition cannot establish statistical superiority. Total
synthesis cost must be counted when evaluating end-to-end economics; it is not included
in the individual recovery-call timings.

The initial comparison accidentally used Codex's native read-only sandbox, which the
restricted remote container cannot run. File reads failed with the known namespace error.
Those trials are invalid and excluded. The corrected comparison uses the same native
execution configuration as actual Simjecture studies, with instructions to inspect only
the supplied records. Corrected results are recorded in `recovery_results.json`.

| Delivery | Correct fields | Recovery wall time | Reported input + output tokens | Cached input (subset) | Native commands |
|---|---:|---:|---:|---:|---:|
| Plain files | 7/7 | 69.19 s | 57,311 | 14,336 | 4 |
| Previous minimal-style brief | 7/7 | 118.27 s | 72,107 | 22,528 | 11 |
| Automatic journal in prompt | 7/7 | 16.36 s | 9,110 | 0 | 0 |

Charging the automatic condition the entire one-time synthesis cost gives **47.39 seconds
and 18,594 reported tokens for synthesis plus recovery**. That excludes common fixture
execution/setup, and is not a billed-credit estimate. Reasoning tokens are already included
in output; cached input is already included in input. All conditions were accurate here;
we observed lower recovery effort rather than a higher scientific success rate. The
single fixture, single model, single trial and fixed execution order limit the conclusion.

## Automated checks and limits

- Full local suite: **639 passed, 9 skipped** for unavailable optional dependencies/runtimes.
- Remote non-root journal, memory, oversight and execution tests: **42 passed**.
- Subsequent targeted journal/supervisor/evidence checks: **47 passed**.
- Ruff and documentation build with warnings treated as errors: passed.

Regressions cover automatic entries without worker notes, source-change detection,
chronology without invented causal links, injected prompt context, idempotent refresh,
artifact tampering, explicit failure records, non-finite JSON, claim-review precedence,
small-study synthesis suppression, total synthesis budget, malformed summaries, invented
citations, and transient provider failure. Journal/brief refreshes do not count as new
scientific progress.

The remote development installation is updated; no public package was released and no
long plasma campaign was restarted. Simjecture's existing hypothesis, counterexample,
prospective-repair and independent-acceptance rules remain in force. A long matched-budget
plasma comparison is still needed to establish research effectiveness.
