# 封存测试挂载点

本公开分支只保存 `tasks/test_manifest.json` 的数量与 SHA-256 承诺，不发布本次 20 题封存测试的载荷、参数、扰动、参考答案、独立验证源码和密钥。它们仍保存在操作员管理的隔离存储中。
