# Qwen3.5-9B 科研决策训练

这是当前科研决策模型的完整**代码与公开协议快照**，与本仓库的 Simjecture 0.7.1 一起使用。唯一基模为 `Qwen/Qwen3.5-9B`，固定修订 `c202236235762e1c871ad0ccb60c8ee5ba337b9a`。支持 LoRA SFT、真实多实验研究轨迹的在线 RLOO、建议归因与独立 C/D 评估。实测硬件为 **2×64GiB Ascend 910**，仿真使用独立远端 CPU。

**从 [训练指南](训练指南.md) 开始。** 指南给出环境配置、教师采集、SFT、自主 RL、GPT 辅助 RL、恢复与评测命令。

|路径|训练内容|当前验证范围|
|---|---|---|
|GPT-6.1 Sol 示范 → LoRA SFT|从结构化研究状态生成实验、参数、组织、模型层级与规模建议|真实小规模 SFT 已完成；完整240条轨迹尚未收齐|
|GPT 主导 Simjecture + 9B 建议 → RLOO|通过完整多仿真研究学习决策与预算分配|真实辅助研究与归因记录已产生；完整80题/16题开发闭环待完成|
|9B 自主实验 → 数值规则 → RLOO|额度不足时训练可客观验证的科研决策|已有真实更新；当前自动工具限于 T01-L1 的一维理想MHD/Alfvén波|
|固定策略服务|原始9B、SFT adapter、RL adapter 的建议接口|已用于真实研究，同组保持固定策略|

自主分支不需要 GPT 参与训练，使用固定数值工具执行器，不包含任意求解器代码生成，也不把规则奖励伪装成 GPT 独立评审。PIC、重联、输运、波粒、跨尺度及跨领域的公开命题已编制；各方向仍需相应求解器和独立参考完成数值资格验证。

完整方案为80训练题、16开发题、20封存测试题，四级难度分别20/4/5；SFT为80×3=240条真实研究轨迹，RL步数随开发收益决定。正式比较20×4，建议归因20×2。科学结论正确性C、实验决策能力D**分别100分**，超时、失败和未完成研究全部保留并评分。见[实验协议](实验协议.md)。

- `research_decision/`：训练、采样、Lab接入、归因、奖励、隔离、调度和评测。
- `science_tools/`：自主分支实际使用的保守一维MHD求解器。
- `tasks/`、`plans/`、`schemas/`、`prompts/`：公开命题、完整研究清单、结构与角色合同。
- `tools/`：可迁移配置、权重校验、执行池登记、新运行计划。
- `scripts/`：本次运行的控制、检查及历史环境辅助脚本。
- `docs/`：实测状态、依赖、来源及未完成内容。

[当前状态与限制](docs/状态与限制.md) 区分代码实现、离线夹具、真实训练和最终科学能力结论。完整已知结论客观评价模块仍待实现/数值资格验证；当前没有最终C/D成绩或科研能力提升结论。

公共Git不包含凭据、服务器连接配置、模型/adapter/优化器/RNG张量、私有科研轨迹和封存测试内容。实际续跑需要原服务器的检查点与数据。测试挂载说明见[sealed/README.md](sealed/README.md)。
