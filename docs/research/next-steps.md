# Next steps

Version 0.1 is the methods and infrastructure preview: a domain-neutral
evidence harness, recorded autonomous campaigns, and a capability framework
that can take a new instrument. That is the released target.

What comes next is scientific use of that harness, not a second set of
release conditions.

## Extend the same tooling

The claim ledger, sandbox, commissioning protocol, and capability framework
are ready for other simulation-gated fields that have a sharp question and a
checkable instrument. Adding a field means installing or authoring an
instrument, writing a problem contract, and running the same evidence rules.

## Hunt independently confirmed new results

Plasma remains the origin domain. A later campaign should produce an
independently inspectable discovery package: a compact law, a matched
counterexample, or a scoped impossibility that survives fresh confirmation
and adversarial attack. A numerical failure or under-resolved run is an
instrument result, not a scientific finding.

## What 0.1 already requires

Any later result still needs prospective contracts, commissioned instruments,
immutable provenance, and guarded claim closure. Those rules do not change
when the field changes.
