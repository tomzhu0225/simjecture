# 0.6.2rc1 release-candidate acceptance

This candidate adds optional local workspaces and conversation projects. It reuses
the existing interactive and autonomous research services. Personal remains the
default; existing conversation directories, study receipts and links are preserved.

## Feature and compatibility checks

The workspace/project implementation passed 190 focused regression checks,
including real browser navigation, existing chat-to-study handoff, hosted workspace
compatibility, scientific-study ownership and static asset checks. The final
project-route change passed a further 52 navigation/client checks. These test sets
overlap and should not be added as independent coverage counts.

Coverage includes:

- separate workspace settings, machine registrations and conversation lists;
- simultaneous browser tabs with explicit workspace selection;
- project creation, shared files, conversation membership and context snapshots;
- preservation of historical paths and study records when changing membership;
- delivery of shared instructions to fresh and resumed agent turns;
- frozen project context and ownership in an autonomous launch contract;
- invalid IDs, path traversal, linked shared files and read-only API controls;
- CLI operations without a browser or HTTP server;
- desktop/mobile layout, figure loading and file downloads.

The local broad suite initially recorded 1,339 passes, five skips and two failures.
The stylesheet-order regression was corrected and retested. The other failure,
an installed FLASH runtime smoke test, reproduced on unchanged v0.6.1 with the
same local runtime. It is not evidence of a new workspace regression. The clean
release check is recorded separately; optional solver tests require their actual
installed runtimes.

## Packaging and privacy

The candidate's package, citation, fallback version, installer and lock metadata
use `0.6.2rc1`. Source distributions build the wheel, and the workspace bundle
contains only the installer's tracked source allowlist. The Python distribution
excludes user artifacts and private directories.

Private operator material used for local inspection is not part of the source,
documentation, package examples or installed defaults. Public-facing fixtures use
generic inputs. Importing existing case reports for inspection neither starts a
new simulation nor creates accepted scientific evidence.

## Scope

Workspace/project management is a local feature in this candidate. The public
trial retains its existing account isolation and single-workspace presentation.
Local workspaces separate research records and settings within a trusted
installation; they do not isolate mutually untrusted operating-system users.

No new paid autonomous plasma campaign was used to validate this organisational
feature. The scientific completion rules and evidence acceptance criteria are
unchanged. See [Projects and workspaces](../how-to/projects-and-workspaces.md)
for the supported UI, CLI and HTTP interfaces.
