# 0.6.1 release acceptance

Version 0.6.1 adds protected report finalization to new minimal studies, repairs
worker/reviewer coordination, and refreshes the documentation and plasma demos.
Existing studies retain their saved policy and scientific records.

## Automated and packaging checks

The release implementation passed **1,324 tests with 7 skips**, documentation
build/link checks, actual CPU WarpX qualification, workspace installation and
recorded-demo verification in [CI](https://github.com/tomzhu0225/simjecture/actions/runs/37750610952).
The version update also passed the installer, documentation-link and finalization
checks (19 tests), a frozen-lock check and a warning-free documentation build.

A clean source distribution builds a wheel that installs into an isolated Python
environment. Runtime cylinder-flow validation data is retained through that
build. Bulky research records and plotting bundles are distributed in the
repository and documentation; they are not runtime dependencies of the Python
source package. The release workflow repeats tests, verifies the tag/version
match and tests the versioned workspace installer before publishing to PyPI.

## Real research and interface checks

The [demo audit](../research/demo-audit-20261008.md) preserves the actual Kepler,
FLASH and FLASH-to-WarpX studies and their budgets, models, outcomes and limitations.
Two additional 30-minute continuations kept their original hypotheses and parent
record hashes unchanged. The island continuation completed five fresh base cases
and two refinements; the coupled continuation completed its additional particle
control and analysis. Both scientific hypotheses remained unresolved.

The new director wake-up path was observed in both continuations. Their report
reviews timed out, exposing finishing-phase scheduling defects. Subsequent fixes
preserve admitted diagnostics, resume the writer after analysis, reuse remaining
review time and allow one bounded review-transport retry. Those repairs have
regression-test coverage; another paid plasma campaign has not established their
real-model completion rate. Original trial outcomes are not retroactively changed.

The visual walkthroughs include actual plasma fields, patch geometry, pressure
maps and evidence maps, with PNG/PDF/SVG exports and source hashes. Both pages
passed desktop/mobile checks in light and dark themes, including image loading,
links and horizontal overflow. Read-only checks of both actual monitors showed
the unreviewed report state with no JavaScript errors. Compact continuation audits
verify 556 retained files. Original classic data and figures remain unchanged.

## Scope

Report acceptance and scientific claim approval are separate. Falsified,
supported within the tested scope, and unresolved remain distinct scientific
outcomes. Neither successful solver execution nor a complete report certifies a
physical claim. The FLASH-to-WarpX example is one-way initial-condition transfer,
not a two-way embedded solver or a generally validated kinetic correction.
